\# Bioinformatics Restart



Documenting my return to bioinformatics after 8 years as a STEM technical editor.



\## Background



I completed a B.Tech in Bioinformatics in 2013, then spent 8 years as a technical editor for STEM books and journals (the last 3 years based in Hamburg, Germany). I'm now rebuilding my hands-on technical skills to re-enter bioinformatics as a practitioner, drawing on strong scientific literacy built from years of editing research across many subfields.



\## What this repository tracks



\- Solutions to \[Rosalind](https://rosalind.info) problems (Python)

\- Practice with core bioinformatics tools and workflows (Biopython, pandas, NGS pipelines)

\- Progress notes as I rebuild and expand my technical skill set



\## Current focus



\- Python / Biopython fundamentals

\- Core bioinformatics concepts: sequence analysis, DNA/RNA processing

\- Working toward: NGS workflows (RNA-seq, variant calling), Nextflow/Snakemake, cloud-based pipelines (de.NBI)



\## Setup



Environment managed with conda:





conda create -n bioinfo python=3.11

conda activate bioinfo

conda install biopython pandas
